# Прототипы GYM AI

Рабочие прототипы, **не слитые в основную версию**. Сохранены с опубликованных страниц
`gym-ai-exflow` и `gym-ai-preview` перед их удалением.

| Файл | Страница | Что это |
|---|---|---|
| `exflow/index.html` | «GYM AI — тест: упражнения и программа» | Пикер упражнений с мышечными зонами, каталог из 53 упражнений, свои упражнения пользователя |
| `preview/index.html` | «GYM AI — превью базы» | Чипсы упражнений и фильтры по зонам |
| `exflow/exercise_library.json` | — | Каталог и зоны из `exflow`, вынесенные в структурированный JSON |

## Почему это не в основной версии

Основная страница (`index.html` в корне репозитория) содержит урезанный каталог:
`exerciseGuides` — 11 записей, без полей `zone` / `muscle` / `tech`.
В `exflow` — 53 упражнения с полным описанием техники и привязкой к 9 мышечным зонам.

При внедрении стоит решить:

1. **Куда живёт каталог.** Сейчас он захардкожен в клиенте. Для мультипользовательской версии нужна таблица в Turso и выдача по `/api/state` или отдельному `/api/exercises`.
2. **Формат.** `exflow` хранит `{icon, ru, en, sets, reps, w, zone, muscle, tech}`, основная версия — `{zone, emoji, text}` в `exerciseGuides`. Форматы несовместимы, нужен один.
3. **Зоны.** `ZONES` из `exflow` (Грудь, Спина, Плечи, Руки, Ноги, Ягодицы, Кор, Кардио, Свободные веса) не совпадают с теми, что есть в основной версии.

## Что уже работает в прототипах

`exflow`: выбор зоны → список упражнений → добавление в день (`addToDay`), свои упражнения в `localStorage`
(`gymai_my_exercises`), настройки (`gymai_pref`), тестовый план (`gymai_test_plan`), фильтр по дням Пн/Ср/Пт.

`preview`: чипсы упражнений (`CHIPS`), фильтры (`filt`, `show`), зона `ZS`.

## Как открыть

Это статические страницы. Достаточно открыть файл в браузере — сборка не нужна.
Данные лежат в `localStorage`, поэтому при проверке сначала посмотрите на пустое состояние.
